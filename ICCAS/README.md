# ICCAS 2026 Paper Project

This directory contains the paper manuscript and official templates for the **International Conference on Control, Automation and Systems (ICCAS)**.

## Files
- [main.tex](file:///root/isaac-go2-ros2/ICCAS/main.tex) - Your main paper draft, adapted to the official `ICCAS.cls` class.
- [Paper-Template_ICCAS.tex](file:///root/isaac-go2-ros2/ICCAS/Paper-Template_ICCAS.tex) - The original LaTeX template.
- [ICCAS.cls](file:///root/isaac-go2-ros2/ICCAS/ICCAS.cls) - The official LaTeX class file.
- `/figures` - To store images, graphs, and diagrams.
- `/poster` - Official A0 poster generation pipeline, editable PowerPoint (`ICCAS2026_Poster_Quadruped.pptx`), and print-ready PDF.
- `ICCAS2026_Poster-Sample.pptx` - Official sample template from ICCAS.
